## 1. 计划导入

- [ ] 粘贴 template.json → 校验通过 → 预览显示 7 餐食 / 4 运动 → 确认导入生效
- [ ] 只含 `meals` 的 JSON：仅增量合并餐食，运动计划保留；相同 id 重复导入不产生重复项，新 id 追加到末尾
- [ ] 只含 `exercises` 的 JSON：仅替换运动
- [ ] 非法 JSON（缺引号/多逗号）→ 「JSON 格式错误」提示
- [ ] `version:"2.0"` → 版本不支持提示
- [ ] meals 与 exercises 均缺失 → 导入内容为空提示
- [ ] `time:"25:00"` / `days:[0,8]` / `type:"夜宵"` / `calories:99999` → 对应中文错误并定位条目
- [ ] 文件导入：选择 .json 文件内容与粘贴等效；选了 .txt 报格式错误
- [ ] 导入后 meta.tdee/dailyCalorieTarget 写入设置页
- [ ] 模板页三区块复制到剪贴板内容完整可用
- [ ] 重复导入两遍，今日页无重复条目
- [ ] 预览条目行内直接展示细节：运动显示训练内容各环节（环节名/具体内容/分钟数）、餐食显示食材清单与做法步骤、备注
- [ ] 预览点运动条目 → 编辑训练内容（改环节名/具体内容/分钟、增删环节）→ 确认导入 → 详情/今日与编辑结果一致（**预览编辑真实生效**）
- [ ] 预览点餐食条目 → 编辑食材清单（增删改 item/amount）与做法步骤 → 确认导入 → 详情页一致
- [ ] 预览中 ✕ 删除某条 → 确认导入后该项不在计划里（**删除真实生效**，非 AI 原样）
- [ ] 预览中改动的名称/时间/热量 → 确认导入后已更新（而非 AI 原值）

# plan-maker-manager-flutter

「知轻」—— 卡路里 / 饮食记录应用的 **Flutter 客户端**。

## 仓库结构

| 路径 | 说明 |
|---|---|
| 仓库根目录 | Flutter 工程本体（clone 后可直接 `flutter run`） |
| [spec/](spec/) | 设计与规格文档：`spec.md`（总规格）、`design.md`（界面设计）、`tasks.md`（任务拆解）、`backup-design.md`（备份方案）等 |

## 相关仓库

- **plan-maker-manager**：uni-app（H5 / App）版源码、Android 离线打包工程与同套 spec 文档
- 本仓库为 Flutter 版独立私库，工程代码与规格文档同仓维护，改动需保持 spec 与代码同步

# plan-maker-manager-flutter

「知轻」—— 单机离线优先、专注卡路里缺口与三大宏量元素管理的**极简减脂记录小助手**（Flutter 客户端）。

知止而后有定，把日子过轻一点。

---

## 🌟 核心特性

- **单机离线优先（Offline-First）**：纯本地数据持久化，不依赖云端账户，100% 隐私安全。
- **快照事实与模板解耦**：计划是模板，打卡是事实。历史数据固化防飘移，不随计划调整错乱。
- **两级食物估算引擎**：内置 500+ 食物成分库端侧毫秒级匹配，云端多服务商（DeepSeek、Gemini、OpenAI 等）专业营养学 Prompt 兜底。
- **科学热量缺口与宏量营养素**：基于 Mifflin-St Jeor 基础代谢与去脂体重动态推导蛋白质、碳水化合物、脂肪克数目标。
- **🔍 今日校验与三方 AI 二次核验（v1.2.0 新增）**：
  - 一键汇总当日所有已打卡摄入与消耗条目，自动合成专业营养学 Prompt 复制到手机剪切板。
  - 支持直接粘贴第三方旗舰 AI（ChatGPT、Claude 等）评估结果，端侧智能结构化解析。
  - 用户可自主多选需采纳修正的条目，一键自动纠偏估算热量与宏量营养素，**严格捍卫用户原始输入文本不变**。
  - 临时加餐与临时运动录入即自动标记为已打卡，体验更轻更快。
- **个性化视觉定制**：内置二次元多套主题预设、自定义全景壁纸（支持等比裁剪）、高透毛玻璃融合底栏。

## 📋 最近版本更新

### v1.2.0（2026-10-06）
- **[新增] 今日校验全屏页面**：
  - 在今日热量缺口卡片底部挂载「🔍 今日校验」入口。
  - 固定高度可滚动总结框，展示今日所有已完成打卡的饮食与运动明细，条目数值与全天汇总严格对齐。
- **[新增] 复制问 AI 快捷工作流**：
  - 一键合并今日记录与专业减脂营养学提示词至剪切板，无需用户繁琐组织文字。
- **[新增] 结构化自动纠偏与用户自主勾选**：
  - 端侧毫秒级解析第三方 AI 返回的 JSON，告别晦涩生硬格式。
  - 自动识别并分类展示“有偏差/建议调整”与“估算准确”条目，显示原值与新值划线对比及 AI 诊断说明。
  - 提供复选框并默认智能预选偏差项，支持用户自主勾选/取消勾选任意条目，仅修正勾选项。
  - 核心铁律保障：**永远不修改用户的原始输入内容，仅修正热量及蛋白质、碳水、脂肪估算值**。
- **[优化] 临时加餐与运动录入体验**：
  - 手动添加的加餐与临时运动，添加即视为已吃/已练事实，自动标记为已打卡完成，无需二次手动打卡。
- **[优化] 今日总结过滤口径**：
  - 预设计划项未打卡执行前坚决不计入今日总结与 AI 校验，防止将未执行的计划误当今日事实。

### v1.1.0（2026-10-01）
- **[新增] 无计划默认三餐骨架**：新用户无需先做繁琐计划，进入即可自由记录早中晚三餐。
- **[新增] 一键转日常计划**：支持将今日满意的餐食一键沉淀为长期固定计划模板。

### v1.0.4（2026-09-20）
- **[新增] 常用预设方案管理**：本地食物库与 AI 测算历史自动沉淀为常用预设库。

## 🚀 快速上手

```bash
# 编译正式 Release APK 安装包

```
